The archive this flake conveys carries no licence text of its own: all 327 entries were listed and none is a `LICENSE`, `NOTICE`, or licence-named file, so the upstream terms above are stated here because nothing inside what this flake distributes states them. Libraries that ship their own notice do so within their own jar — `spring-boot-3.4.8.jar` carries `META-INF/LICENSE.txt`, `log4j-api-2.24.3.jar` carries `META-INF/LICENSE` — and those that do not, such as `logback-classic-1.5.18.jar`, travel with no text at all, so there is no aggregate notice to point at.

`clipcascade-server` is a wrapper that runs `java -jar` over the fetched archive, so the Java modules the runtime links are nixpkgs' JDK's own closure, recorded there rather than restated here.
